# Tempora icons

| File | Used for |
| --- | --- |
| `app.ico`, `app-64.rgba` | The dashboard's executable and window icon: the Lanes mark, three rows of colored activity. |
| `recorder.ico` | The recorder's executable icon: the mark with a red record button. |
| `tray-recording.ico`, `tray-paused.ico`, `tray-attention.ico` | The notification-area icon, one per recorder state: a smaller mark with a green dot, amber pause bars or a red exclamation mark. |

The build uses these files directly. To change an icon, replace its file.
